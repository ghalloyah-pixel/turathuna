# تراثنا أول وتالي 🇦🇪

**من ذاكرة الأجداد… إلى جيل اليوم.**

مساحة رقمية تجمع ملامح من التراث الإماراتي (أمثال، كلمات، سنع، حكم، أشعار، عادات، حرف…) بهدف حفظ الموروث وتعريف الأجيال الجديدة به بطريقة سهلة وتفاعلية.

> **قاعدة مهمة:** لا نختلق أي مثل أو كلمة أو قصيدة. كل محتوى معتمد على مصادر يمكن الرجوع إليها (مثل مركز حمدان بن محمد لإحياء التراث وكتاب «المتوصف»).

## الأقسام الجاهزة
- الصفحة الرئيسية + بطاقات الأقسام
- الأمثال الشعبية (مع توثيق)
- الكلمات الإماراتية + الألفاظ الدخيلة
- السنع (مواقف تفاعلية)
- صفحة المصادر
- اختبار تفاعلي + زر «فاجئني بتراثنا»
- مفضلة + وضع ليلي + بحث

## باقي الأقسام
قيد التطوير — لن يُضاف محتوى إلا بعد توثيقه من مصادر موثوقة.

## التشغيل المحلي
افتح ملف `index.html` في المتصفح.

## GitHub Pages
بعد رفع الملفات على مستودع عام وتفعيل Pages من Settings، سيظهر الموقع على:
`https://YOUR-USERNAME.github.io/REPO-NAME/`
